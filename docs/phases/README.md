# Fases - Guia unificada

Este directorio tenia multiples archivos por fase. Para simplificar navegacion, el documento maestro por fase es:

- Fase 4: `FASE4_SISTEMA_NIVELES_ESPECIFICACION.md`
- Fase 5: `FASE5_ESTABILIZACION_Y_PILOTO.md`
- Fase 6: `FASE6.md`
- Fase 7: `FASE7.md`

## Politica de documentacion

1. Cada fase debe tener un unico archivo maestro (`FASEN.md`).
2. Los demas archivos de esa fase se mantienen como anexos/evidencia historica.
3. Cualquier actualizacion funcional nueva primero se refleja en el maestro y luego, si aplica, en anexos.
